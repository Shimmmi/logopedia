# LogoPed — копи-дек

Обращение на «вы». Без восклицаний, англицизмов и жаргона провайдеров.

## Глоссарий

- ученик — ребёнок в картотеке
- занятие — единица расписания
- заключение — документ по итогам диагностики
- динамика — оценки по направлениям
- кабинет — личное пространство специалиста

## Ошибки

- Сеть: «Не удалось загрузить. Проверьте соединение и повторите.»
- 401: «Сессия истекла. Войдите снова.»
- 403: «Недостаточно прав.»
- 404: «Страница не найдена.»
- 429: «Слишком много попыток. Подождите минуту.»
- Почта недоступна: «Сервис почты недоступен. Попробуйте позже.»

## Пустые состояния

- Ученики: «Пока нет учеников. Добавьте первого, чтобы вести картотеку.»
- Занятия: «На сегодня занятий нет.»
- Документы: «В этой папке пока нет файлов.»
- ИИ: «История пуста. Сгенерируйте первый документ.»
- Уведомления: «Новых уведомлений нет.»

## Письма

Тема подтверждения: «Подтвердите почту — LogoPed». Одна кнопка, код — запасной вариант.
